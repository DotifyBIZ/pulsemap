# Pulsemap

Pulsemap is a local-first WiFi site survey and planning tool for Windows. It predicts coverage, takes live measurements on site and recommends where to put access points. It has no account, no server and no telemetry.

**Who it is for:** people who survey and plan WiFi networks, indoors and outdoors.

**Where it runs:** on the user's own Windows 10 machine (build 19041 or later, 64-bit). There is no hosted part. The installer is published on [GitHub Releases](https://github.com/DotifyBIZ/pulsemap/releases). It is not code-signed.
